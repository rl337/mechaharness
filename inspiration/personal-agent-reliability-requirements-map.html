Personal agent reliability requirements map

Maps backlog items from personal-agent-reliability-inspiration.md (MH-PA-*) to modules and user stories.

Coverage: story means a persona story exercises an integrated library path; partial means helpers/schemas ship but auto-wiring or host integration remains open (see Gaps); gap means the product contract is not shipped. Inspiration status: proposal, not an accepted requirement.

Ownership: MechaHarness owns reusable graph primitives, recipes, grants, checkpoints, and audit envelopes. The AI assistant host owns personal identity, memory content, scheduling, and proactive prioritization. home_network owns supporting state/backup/health infrastructure.
