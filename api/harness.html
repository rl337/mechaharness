mechaharness.harness.base

Harness architecture hierarchy.

AbstractHarness is an agent: one run() is a finite lifecycle of inference calls. Families specialize prompting, tool-call interpretation, and termination. The shared loop emits EventLog records, prices cost, and checks tool grants. Inference is injected via Strategy — harnesses never talk to providers directly.
