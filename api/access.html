mechaharness.core.access

Cost units and deny-by-default tool grants.

Ability is a five-step scale; higher ability costs more. Grants are open identity: a class hierarchy with wire form namespace:name (for example core:fs.read, acme:widget). Unknown namespaced keys round-trip; bare names are rejected.
