Litmus

A user story is valid only if a persona can walk it through the product CLI verb surface: real inputs in, real lane or recipe execution, hard observables out. Case-bag verbs (decision_case, lifecycle_case) failed this litmus and have been removed.

Clarification (post Wave 3): If the claim is a valid product story and the graph path is missing, add the recipe/runners — do not demote the story to unit-only. Unit tests still cover helpers; stories own the walk.
