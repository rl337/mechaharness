Inspiration requirements map

Maps each requirement in dev-blog-inspiration.md to the MechaHarness module that owns it, current gap status, and whether June (orchestrator client) or MechaHarness implements the surface.

Ownership reminder: MechaHarness owns protocols, DI hooks, and parameterized graph templates. June owns scheduler, task runner, document manager, knowledge graph, and issue tracker — it instantiates templates and implements providers; it does not own template definitions.

June task-runner shape

  1. Load persistent goal (June).

  2. Pick a MechaHarness GraphTemplate and bind host tools / providers / envelope.

  3. LinkageResolver.resolve → fail closed on missing edges.

  4. GraphExecutor.run (checkpointed).

  5. On wake: re-resolve environment/linkage, then resume if fingerprint matches.
