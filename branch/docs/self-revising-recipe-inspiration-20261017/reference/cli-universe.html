CLI universe

Surface

Value

Package

mechaharness.cli_universe, cli_infer_runner, cli_instrumentor

Story harness

kind: cli with scenarios/*.yaml

Stability

evolving (Wave 1+: grow verbs as stories migrate)

Role

Hand-built concrete capability graph for the host CLI/TUI — not a GraphTemplate / Agentic Recipe. Commands are verb-led with optional params and product defaults. Soft points stay the UI answer seam elsewhere; this graph grows by adding hard nodes and instrumentor verbs as user stories migrate.

Concept

Module

Graph factory

build_cli_universe_graph (cli:infer node)

Infer runner

CliInferRunner (reason-lane Completer, core:inference + core:cost)

Instrumentor

CliInstrumentor + cli_diagnostic_verbs + cli_acceptance_verbs (infer, tool_loop, run_recipe, routing/parity, completer flavors, capture preflight, host-kit submit-once, judge_route, clocks, …)

Event stamps

StampingEventLog over injectable DateTimeService

Event tap

tapping_event_log on the blessed executor path (HF-05)

Distinct from:

  • Durable generator scripts (durable_generator_script) — IoC start/answer/inspect (fold into CLI later)

  • Agentic Recipes — GraphTemplate soft-point catalogs (verify_repair, …)

Story layout (canonical acceptance)

All user stories are migrating here. New acceptance is kind: cli + scenarios/*.yaml. One story may own many concise scenarios (one claim each):

stories/<id>/
  story.json
  scenarios/
    event_types.yaml
    event_timestamps.yaml
  response.json          # cassette when needed

YAML is CLI-shaped; expect: is test-only (hard equality). Cassette vs live is harness/Config (MECHA_STORY_BACKEND, MECHA_BASE_URL, MECHA_MODEL), not YAML.

Intent check

Before migrating a story, re-read story.json footnotes, docs/inspiration/, and REQUIREMENTS.md. Map normative claims → scenario files; do not copy legacy soft expects blindly. See .cursor/skills/user-stories/SKILL.md.

Migration program

Convert every legacy request.json / op story onto CLI (or temporary durable_generator) YAML. Each wave adds only the CLI verb or harness assert needed:

  1. Observability / one-shot infer (OBS-*) — done

  2. Former harness_runs / pass-through / tool-loop / cassettes / host DI / judge route — done (harness_runs runner removed)

  3. Graph execution + recipe catalog — next

  4. Decision plane / remaining judge ops

  5. pure_api + context/eval surface

  6. Fold durable IoC into CLI when ready

When a legacy family has zero stories left, delete its op-dispatch runner.
