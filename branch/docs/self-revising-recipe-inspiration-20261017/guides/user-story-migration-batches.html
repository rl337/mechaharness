User-story → CLI / user_story migration batches

Surface

Value

Status

living checklist

Destination

kind: user_story scenario YAML (wraps product CLI verbs)

Already done

fangore_insp_guidance_resume_idempotent, nubble_anthropic_cassette_infer, nubble_run_cost_events

Goal

Convert every remaining acceptance story from legacy kind: cli script YAML (and especially probe:) onto the persona-task harness: environment → graph → steps → complete → cleanup.

Production CLI verbs stay as designed. Probes only until a product verb exists for that claim.

Counts

  • Done (user_story): regenerate via scripts/generate_user_stories_md.py

  • Wave 3 (P2–P4 rewrite): case bags removed; see instrumentation migration

  • Wave 4+: remaining work is recipe-first groups G0–G7, not thin-verb then YAML wrap — see recipe expansion

Wave order

  1. Product batches A–F (mechanical YAML + narrative tighten; no new verbs) — done.

  2. Probe batches P1–P4 — done (P3 demotions retracted; restore in G0).

  3. Instrumentation (Wave 3) — case-bag verbs removed; gold = soft-bind + execute + cassette/live (plan).

  4. Recipe expansion (Wave 4+) — invent/extend Agentic Recipes + runners, then migrate probes / promote shape-only stories (groups). P5–P10 checklists below are historical inventory; work them via G0–G7, not as probe→thin-verb waves.

  5. After each batch: regenerate docs/guides/user-stories.md, ratchet fail_under if coverage rose, keep ./run_checks.sh green.

Per-story checklist

  1. Rewrite narrative as one persona walk (CLI host → graph → steps → verify).

  2. Split if the walk cannot stay one task (see split review).

  3. Convert scenario(s) to kind: user_story; set story.json kind accordingly.

  4. Sync twins if present; update cross-refs that cited the old bag id.

  5. Prefer product verbs in steps[].do — no probe.
