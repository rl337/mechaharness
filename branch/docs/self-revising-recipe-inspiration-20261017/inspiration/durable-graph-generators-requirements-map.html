Durable graph generators requirements map

Maps themes from durable-graph-generators-inversion-of-control.md and normative durable-graph-generators.md (DG-* / R-IOC-*) to modules and user stories.

Coverage: story means a persona story exercises an integrated library path; partial means helpers ship but host/adapter integration remains open; gap means the product contract is not shipped.

Ownership: MechaHarness owns the generator contract, yields, continuation persistence, controller auth, ScriptedDriver, events, and node components. Hosts own frontier session context, artistic policy, MCP process lifecycle, and CLI presentation. MCP is an adapter, not core.
