OpenAI Dots agent safety requirements map

Maps backlog items from openai-dots-agent-safety-inspiration.md (MH-DOTS-*) to modules and user stories.

Coverage: story means a persona story exercises an integrated library path; partial means helpers/schemas ship but auto-wiring or host integration remains open (see Gaps); gap means the product contract is not shipped. Inspiration status: proposal, not an accepted requirement.

Principle: Persistent context must never imply persistent permission.

Ownership: MechaHarness owns enforceable graph execution, independent action review, and resumable authorization seams. June owns goals, memory, and user-facing policy configuration.
