MechaHarness documentation

Build model-backed applications with configurable inference providers, agent loops, tool grants, cost accounting, event logs, and resumable execution graphs. Requires Python 3.9+. This documentation describes version 0.18.0.

Start without a provider account:

pip install mechaharness
mechaharness run "Hello" --backend mock --family pass_through --model mock

Use Install & quick start for a first run, Local OpenAI-compat backend (openai_local) for cloud or local endpoints, and Dependency injection to configure a host. See Architecture for component ownership and integration boundaries.
