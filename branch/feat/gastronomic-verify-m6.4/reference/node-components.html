Node components

Node components are sub-node elements that must render within a parent graph node (GraphNode). They are not free-floating world-graph nodes.

Normative rules: Dynamic tool graph and node components.

Query

from mechaharness.node_component import node_components_for
from mechaharness.graph_templates import (
    FanOutAggregateTemplate, GraphTemplateParams,
)

graph = FanOutAggregateTemplate().instantiate(
    GraphTemplateParams(goal="demo", branch_payloads=[{"id": "a"}])
)
comps = node_components_for(graph)
assert all(c.parent_node_id for c in comps)

Traversal

traversal_from_events projects EventLog-like payloads into component-aligned records (parent + kind + status) for host lighting. Prefer aligning with RolloutGraph via execution_node_id when a graph node exists.

Recipe obligation

Every Agentic Recipe reference page SHOULD list node components per graph node (see .cursor/skills/agentic-recipes/SKILL.md). Soft points are soft_point components of the nodes that expose them.
