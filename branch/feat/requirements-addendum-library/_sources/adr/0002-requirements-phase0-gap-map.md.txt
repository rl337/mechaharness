# ADR 0002: Requirements Phase 0 gap map

## Status

Accepted (Phase 0 baseline for REQUIREMENTS.md addendum incorporation).

## Context

REQUIREMENTS.md (library track + local inference host lanes) was refined with the
2026-09-25 context/memory/decision-plane addendum. Phase 0 maps contracts onto
existing modules and records gaps before growing APIs. No second EventLog, judge
schema, policy authority, or permission path.

Baseline ID set (refined in place unless marked new): INF-01/03, JDG-01–04,
POL-01–04, RTE-01–03, GAT-01–04, VER-01–03 (+ new VER-04), GRF-01–04 (+ new
GRF-05/06), CTX-01–04 (+ new CTX-05–09), OBS-01–03 (+ new OBS-04), EXP-01–04.

## Decision

Reuse existing modules; extend types and helpers rather than introducing parallel
services. Host identity remains env-configured local inference (no named appliance
in requirements).

## Mapping

| Area | Module | Status at Phase 0 | Gap |
|------|--------|-------------------|-----|
| INF-01/03 | `operation_registry.py` | Name registry only | Typed `OperationContract` (scopes, effects, idempotency, version bind) |
| POL-01 decision plane | `judgement_policy.py`, `inference/judge.py` | Judge + pure decide | Named Choice/Score/Noul surfaces; widen verdict vocabulary over time |
| POL-03 convergence | harness loops | max_turns / attempts only | Versioned `ConvergenceContract` with budgets and terminal status |
| RTE | `routing.py` | Lane routing + shadow judge | Decision-backend shadow comparison on matched snapshots |
| GAT | `core/access.py` | Central grants | Align effect reconciliation with GRF isolation |
| VER | `graph.py` | `verify_node` / `bounded_repair` | Strongest-oracle selection; VER-04 fixture qualification |
| GRF | `graph.py` + EventLog | Checkpoint/resume | Edge taxonomy, effect isolation, hierarchical fan-in, interrupt boundaries |
| CTX | `context_experiments.py` | CTX-01–04 flags | CTX-05 compiler/manifest; 06–09 flagged experiments |
| OBS | `decision_log.py` | Basic DecisionRecord | Learning-record fields, topology metrics, offline export without leakage |
| EXP | `research.py` | Noninferiority promote/rollback | ATK search space + ablation reporting |

## Baselines to freeze

- Harness success/cost: existing Completer + harness family fixture runs
- Decision: FixtureJudgeProvider + deterministic `decide()` replay
- Topology: synthetic ExecutionGraph timing fixtures (OBS-04)

## Consequences

Phases 1–5 implement the gaps above behind existing DI hooks. Optional CTX/RTE
mechanisms stay off until EXP-04 reports support activation.
