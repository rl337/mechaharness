Audited infer-accept (audited_infer_accept)

Agentic Recipe. RDG-aligned generate → QA → gate spine. Modality (text | image) only swaps decide/QA node kinds. Hosts bind runners; MechaHarness owns topology, criteria freeze, distinct principals, and repair routing.
