Coding-delegate suites (development graph)

Goal

Make MechaHarness a reliable handoff surface for expensive coding: Cursor (or another driver) answers short guidance; a local guided_coding / project_coding graph owns the token-heavy edits under stable contracts, verify/repair, and resumable sequential arcs.

Live Completer is the gate. Static coding_writes / cassette greens are provisional mirrors until the same suite passes under MECHA_STORY_BACKEND=live + MECHA_BASE_URL.

delegate_pkg stages (concrete stories)

  1. fangore_delegate_list_bootstrap — instruction_mode: list with two todos (package + test); assert mode=list and pytest green.

  2. fangore_delegate_guidance_thorough — answer soft point thorough; must write inc() and README.md with Usage.

  3. fangore_delegate_red_green — add test_double + implement double() until pytest green under verify/repair.

  4. fangore_delegate_refactor — rename Widget → Gadget across package, tests, README; forbid leftover class Widget.

Authoring: suites/delegate_pkg/suite.yaml + stages/*.yaml (+ optional sources/ / materialize-stage-files).

# Static (provisional)

Driver graph (product)

Cursor / MCP client
  → generator_start(guided_coding, goal|instructions, verify_runs, …)
  → advice_requested (external_guidance)
  → generator_resume(choice)   # minimal | thorough
  → ProjectCodingLocalWork (tools + Completer + verify_repair*)
  → completed | failed(verify_runs_failed)

Story suites keep that graph honest whether pytest or MCP drives them.

Non-goals (yet)

  • Replacing Cursor’s agent with MechaHarness for all edits

  • Hosting Comfy / media lanes inside coding suites

  • Auto-promoting live suites into default CI (live stays opt-in)

  • A dedicated MCP-only story suite (transport parity, not a new arc)
