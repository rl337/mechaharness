Guided coding (guided_coding)

Agentic Recipe. Frontier driver (Cursor MCP) answers short engineering guidance; local openai_local inference classifies oneshot vs todo list, implements under workspace tools with pre/item/post acceptance, then an audited infer-accept tile gates quality (RDG-aligned). Token-heavy coding stays off the Cursor account.

When to use

  • Cursor (or another MCP client) should guide approach/constraints only

  • Local OpenAI-compat models should edit files and run tests in the project tree

  • Instructions may be a oneshot or an ordered list (with conflict refine + post-list AC)

  • Quality gate needs distinct decide/QA principals + frozen criteria (not only verify_repair)

MCP wiring

Inference endpoints belong on the Cursor MCP server env block (not a required project .env). Set MECHA_MCP_HOST=project_coding so the stdio adapter builds ProjectCodingConfig. See Durable graph generators.
